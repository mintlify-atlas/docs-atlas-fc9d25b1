## What Calculator App Can Do

<CardGroup cols={3}>
  <Card title="Natural Language" icon="comment" href="/features/natural-language">
    Type `9 squared` or `sqrt of 16` instead of formal notation.
  </Card>
  <Card title="Exact Fractions" icon="divide" href="/features/fractions">
    Compute `1/2 + 1/3` or `2 1/2 + 3/4` with exact rational arithmetic.
  </Card>
  <Card title="Equation Solver" icon="equals" href="/features/equation-solver">
    Solve linear and polynomial equations like `2x+4=10` automatically.
  </Card>
  <Card title="Variables" icon="x" href="/features/variables">
    Assign `x=5`, then use `x` in any expression across the session.
  </Card>
  <Card title="Math Functions" icon="function" href="/features/math-functions">
    Built-in `sqrt`, `sin`, `cos`, `tan`, `log`, `pi`, and `e`.
  </Card>
  <Card title="Meme Mode" icon="face-laugh" href="/features/meme-mode">
    Toggle meme mode for easter-egg responses on famous internet maths.
  </Card>
</CardGroup>

## Get Running in Seconds

<Steps>
  <Step title="Install the package">
    ```bash
    pip install calculator-app
    ```
  </Step>
  <Step title="Launch the REPL">
    ```bash
    calc-app
    ```
  </Step>
  <Step title="Enter your first expression">
    ```
    > 2 1/2 + 3/4
    = 3 1/4

    > 2x + 4 = 10
    x = 3

    > 9 squared
    = 81
    ```
  </Step>
  <Step title="Quit when done">
    Type `quit` or press <kbd>Ctrl</kbd>+<kbd>C</kbd> to exit.
  </Step>
</Steps>

<Note>
  Calculator App requires Python 3.10 or later. See the [Installation guide](/installation) for full setup instructions and development installation steps.
</Note>
